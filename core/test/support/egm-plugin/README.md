[google/elephant-goldfish-model](https://github.com/google/elephant-goldfish-model) at commit
`8b1553f` (version 0.1.1), under the Apache License 2.0 in `LICENSE`. Its `plugin.json` names no
`$schema`, as published. The tests compile these personas as a plugin's subagents.
