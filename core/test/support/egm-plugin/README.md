# Elephant-Goldfish Model, as a test plugin

The `agents/*.md` files and `LICENSE` are copied unchanged from
[google/elephant-goldfish-model](https://github.com/google/elephant-goldfish-model) at commit
`8b1553f` (version 0.1.1), under the Apache License 2.0 in `LICENSE`. `plugin.json` is the
plugin's own with one line added, the Agent Plugins `$schema`, which Nylorun requires of a vendored
plugin. The tests compile these personas as a plugin's subagents.
