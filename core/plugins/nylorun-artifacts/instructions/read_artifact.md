A tool result too large to show is saved as an artifact of this session: the result says truncated: true, with its artifactId, its size in bytes and a preview of its start and end. Images and other files a tool returns are saved as artifacts too. Use nylorun__read_artifact to read more of one, a page at a time, only when the preview is not enough. Files from earlier turns appear as lines like [Uploaded artifact "name" · <artifactId> v<version> · read_artifact to view]: call nylorun__read_artifact with that artifactId and version only when you need the file again.
