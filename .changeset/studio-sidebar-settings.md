**Studio: one session list, and Tenant settings in the sidebar.** **Sessions** replaces the sidebar's agents and their nested sessions: one table of every session in the Tenant (session, agent, owner, status), filtered to an agent with the table's Agent filter or the agents listed under Sessions in the sidebar, each with its session count. A flow's embedded agent that has sessions is a filter too. **New session** starts a session of the filtered agent, or of the agent picked from its menu, through the vault picker as before. Sessions show in the list before any agent registers; the Tenant overview shows only while there are neither. Sandboxes and Artifacts sit under Sessions. A Runtime that answers credential coverage without `entries` starts the session with no vaults instead of failing. The filtered list is `/sessions?agent=<agentId>`; `/agents/<agentId>` redirects there, and session URLs are unchanged. Models and Credentials are their own sidebar entries, pinned to its bottom, instead of tabs under one **Tenant settings** entry, and selecting the Tenant in the sidebar's header opens its Overview, beside the Runtime's status (Running, Connecting or Offline); the sidebar's footer of agent count and status is gone. Settings URLs are unchanged. A Tenant path Studio has no page for shows "Page not found" instead of the agent list.
