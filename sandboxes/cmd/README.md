# The module's commands

The two binaries this module builds: the sandboxes service, and the computer agent an actor runs when it is a computer.

## Folders

- [sandboxes](./sandboxes/README.md): the sandboxes service — API, backends, edge, gateway and keys provider.
- [computer](./computer/README.md): the computer agent, `ghcr.io/nylorun/computer`.
